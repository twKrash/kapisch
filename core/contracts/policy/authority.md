# Human authority

Recommendation, human decision, approval, and permission for a side effect are separate facts. An authoritative human gate requires either a host/adapter-produced inbound-human receipt bound to exact action text, session-local action ID, run, gate, target/scope, and observed time, or an explicitly externally supplied human-authored artifact bound to exact bytes and the same target. The controller transports and persists these inputs; it must not create either evidence source from model or controller text.

A receipt records observable origin, not cryptographic identity. A digest binds bytes, not authorship; do not claim stronger guarantees. The human owns the decision input, the host adapter owns receipt provenance, and the controller alone serializes an immutable accepted snapshot after that explicit choice. The reviewer owns review judgment; the adapter owns observed invocation facts; the controller binds but never authors those external facts. Accepted snapshots are separate immutable artifacts with explicit governing-source dependencies and amendment/supersession edges. Approval cannot override an active normative source. Changed dependencies stale promotion/execution until re-evaluation and fresh approval; historical accepted snapshots remain unchanged.
