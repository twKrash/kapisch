# Request normalization

Interpret explicit user control before inferred intent. Separate desired outcome, in-scope repository surface, constraints, acceptance criteria, requested checks, and side effects. Resolve workflow as advisory, review, task, or milestone; do not infer a larger lifecycle from a narrow request.

Preserve ambiguity that affects policy, permissions, architecture, material scope, or irreversible effects as an explicit human decision. Do not let a profile, role name, previous run, or generated artifact decide user intent. The controller records its interpretation and evidence; core validates closed values and bindings, not English meaning.
