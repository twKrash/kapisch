# Review policy

Review is an independent judgment, not a controller-authored checklist result. Bind invocation and result to the exact target, scope, and repository revision. Iteration review covers its declared delta; whole-branch review uses fresh context and the complete target. A later implementation delta invalidates prior final evidence.

A standalone review returns findings only. An authoritative approval or readiness claim requires validated review provenance and current pre/post/current repository-state evidence. The reviewer path must be enforced mutation-free for approval; read-only instructions or an unverified tool allowlist alone do not prove confinement. If reviewer identity, context, enforcement, or validator is unavailable, block authority rather than downgrade silently.
